# sola cafe

仕事帰りに、一人で落ち着いて過ごせる
静かなカフェをテーマに制作した
架空カフェサイトです。

## URL

https://b-akiyama.github.io/sola-cafe/

## 使用技術

- HTML
- CSS
- GitHub Pages

## 工夫した点

- 暖色系で統一した夜カフェの世界観
- 一人で落ち着ける空気感を意識したデザイン
- 余白を活かしたシンプルなレイアウト
- スマホでも見やすいレスポンシブ対応

## 制作イメージ

「仕事帰りに、自分を取り戻せる場所」

をコンセプトに、
静かな夜のカフェをイメージして制作しました。
